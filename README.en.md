# more-ui-skill

[中文](README.md) | English

**More UI** — a skill for diagnosing and fixing UI grid, alignment, spacing, sizing, and responsive layout issues.

It addresses:

1. Inconsistent page grids, alignment, spacing, and sizing.

2. Responsive layout misalignment, overflow, and overlap.

3. Over-editing UI during fixes in ways that break design intent.

4. Missing reusable inspect / optimize / verify workflows for layout work.

## Install

Ask your agent to run:

```bash
npx skills add BranchCrypto/more-ui-skill
```
